## Обязательный способ проверки

- Собирать и запускать production-версию только через локальный Docker.
- Для визуального сравнения и интерактивных тестов использовать встроенный браузер Codex.
- Сверять оригинал и localhost при одинаковом CSS viewport минимум на desktop, tablet и mobile; рекомендуемые контрольные ширины: 1904, 1280, 796/768 и 375/376 px.
- Проверять не один скрин первого экрана, а каждую исходную секцию, её состояния, скролл и анимации.
- Не сообщать о готовности до завершённого визуального аудита всех исходных блоков.

В предыдущем чате вкладка встроенного браузера была открыта на `http://localhost:8080/`, но управляющее подключение падало до выполнения команд с ошибкой `failed to write kernel assets ... os error 3`. Именно ради свежего браузерного сеанса работа переносится в новый чат. Не заменять встроенный браузер Chrome или отдельным Playwright, если пользователь снова явно требует встроенный браузер.

## Важные находки по живому исходнику

CSS загружается в таком порядке:

1. `assets/css/38d310b04484773c.css`
2. `assets/css/hero-motion.css`
3. `assets/css/overrides.css`
4. несколько inline-блоков CSS/JS
5. `assets/css/large-screens.css`

Нельзя копировать только первый CSS-файл: итоговый вид заметно меняется поздними override-слоями.

- Hero gradient: `linear-gradient(157deg, #fff 17.71%, #ffcdb3 43.16%, #ffa4b6 58.2%, #ffb2e9 73.32%, #d4d6ff 90.8%, #fff 103.16%)`.
- Final CTA live gradient: `linear-gradient(157deg, #fff 17.71%, #ffd1b9 43.16%, #ffabbc 58.2%, #ffb8eb 73.32%, #d7d9ff 90.8%, #fff 103.16%)`.
- Final CTA скрывает dust/subtitle в итоговом live-виде, но оставляет две анимированные blob-подложки (7/8 s) и shine (6 s).
- Reveal: 900 ms, смещение 32 единицы макета, easing `cubic-bezier(.16,1,.3,1)`.
- «Любой контент»: inline-автоплей 8000 ms на состояние; 20 состояний, клики перезапускают цикл; mobile swipe проходит по той же последовательности.
- Desktop use-cases body: левая колонка 24.5%, gap 32, правая панель aspect-ratio `995/558`.
- FAQ desktop: flex-колонки, column-gap 32, внутренний gap 20. Tablet и mobile складывают колонки вертикально.
- FAQ основан на независимых checkbox, поэтому мультиселект обязателен.
- Comparison mobile: ширина сетки 690 единиц, треки `90 100 120 120 120 140`; первые две колонки sticky; градиент второй колонки рисуется одним полотном высотой 348 единиц.
- Roadmap: desktop column 320, pad 40, dot 32, halo 20, core 6; линия на y=16; достигнутый progress до августа 2026 — восемь интервалов плюс 4 единицы.
